Abstract: The Airport Flight Board & Scheduler system is a console-based Java application designed to manage flight display boards and track flight schedules using foundational programming concepts. The project utilizes primitive data types and Scanner console input to take flight details like flight numbers, departure times, and gate allocations. A 2D array matrix representation models the flight schedule layout and terminal gate occupancy, while 1D arrays store flight status and delays. Selection statements such as switch-case and nested if-else ladders handle interactive user menus and operational status updates. Iteration through for and while loops enables live board updates, delay calculations, and searching techniques for specific flights. Custom methods modularize functions like schedule display, average delay computation, and total flight counting. Additionally, recursion is applied to compute schedule priority calculations. This modular implementation efficiently processes flight management workflows using core procedural Java concepts.
